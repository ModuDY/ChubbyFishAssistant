# 桌宠右键菜单重设计方案（V2）

> 触发：2026-10-21 用户截图反馈——「动作点播」展开后菜单比窗口还高、底部被裁，卡片压住角色与气泡，层级像一长串目录。
> 结论：**保留「单卡片翻页」形态，重做信息架构与定位/尺寸规则**；不引入二级浮窗、不引入径向菜单。
>
> **实现状态（2026-10-21 已落地）**：`src/pet/menuPlacement.ts`、`menuModel.ts`、`PetMenu.tsx` 新增；
> `PetRoot.tsx` 改为「实测尺寸 → placeMenu → 渲染」；`pet.css` 菜单段重写；Rust `MENU_SPACE` 160 → 232。
> 与初稿的两处差异：卡片宽取 **216px**（保证「陪我玩会儿」三枚 pill 一行放得下）；「形象与位置」页承载形象切换 + 回到初始位置。

## 2. 设计目标

1. **3 次操作内**点到任意动作（右键 → 动作点播 → 搜索/分类 → 点击）。
2. **0.6 ~ 1.5 任意缩放下完整可见**，不压气泡、不出窗口。
3. **一屏一层**：卡片里只有「条目」，不再有折叠组套滚动区。
4. **键盘可达**：方向键 + Enter + Esc，搜索框输入即筛选。
5. 视觉上像「桌宠的浮层 HUD」，不是「Windows 系统菜单的仿制品」。

## 3. 交互模型

### 3.1 两层结构

```
L1 快菜单（默认，8 行 + 1 排 pill）
├─ 陪它玩： [喂点吃的] [陪我玩会儿] [露一手]     ← 三枚并排 pill，一行
├─ 跟我聊聊…            （AI 关闭时隐藏）
├─ 让它自己说一句        （AI 关闭时隐藏）
├─ 一键签到
├─ 启动 / 停止 API 网关   [状态点 + 运行中/已停止]
├─ ─────────────
├─ 动作点播…            ›
├─ 形象与位置…          ›
├─ ─────────────
├─ 重新加载
└─ 隐藏桌宠

L2 动作点播（同一张卡片翻页）
├─ ‹ 返回 | 动作点播 | 共 106
├─ [🔍 搜索动作…]
├─ 分类 chips（换行，不滚动）：最近 · 全部 106 · 待机 8 · 工作 6 · 积分 6 · 点击 5 · 碎碎念 3 · 生活 28 · 才艺 16 · 特效 4 · 节日 19
├─ 扁平列表（单列，32px/行，仅此一处可滚动）
└─ 固定底栏：[⟳ 随机来一个]  当前结果数

L2b 形象与位置（同一张卡片翻页）
├─ ‹ 返回 | 形象与位置
├─ 单选列表：内置形象 / 素材包…（当前项：左侧实心点 + 强调色文字）
├─ 未发现素材包时的路径提示
└─ 分隔 + 回到初始位置
```

**为什么砍掉「呼出主窗口」与「回到初始位置」**：双击角色本来就呼出主窗口，L1 再放一行是重复；回到初始位置属于低频设置，移到「形象与位置」页后 L1 才能压到 8 行、在 `scale=1` 的 352px 可用高度内**不滚动**。

**为什么不是三级菜单**：窗口右侧只有 232px 槽位，子菜单再向右一定被裁；hover 展开在无边框窗口边缘容易误触。**翻页 + 搜索**比「组折叠」快得多——用户记得「吃西瓜」，不记得「它在生活组第 9 个」。

### 3.2 打开 / 关闭

| 动作 | 行为 |
|---|---|
| 右键角色热区 | 打开 L1，锚点 = 光标位置（不再是固定槽位） |
| 菜单已开时再次右键 | 关闭（toggle），不重开 |
| 点击卡片外空白 | 关闭 |
| Esc | L2/L2b → 回 L1；L1 → 关闭 |
| 执行任意条目 | 关闭并执行 |
| 窗口失焦 | 关闭（桌面操作时不悬着一个菜单） |

### 3.3 定位算法（纯函数，可单测）

`placeMenu(anchor, size, viewport, petRect)`：

1. 默认：`x = anchor.x + 6`，`y = anchor.y + 6`（光标右下）。
2. 水平：若 `x + w > viewport.w − 8` → 翻到光标左侧 `x = anchor.x − w − 6`；仍越界则夹紧。
3. 垂直：若 `y + h > viewport.h − 8` → 翻到光标上方 `y = anchor.y − h − 6`；仍越界则夹紧。
4. **避让角色**：若菜单矩形与角色包围盒重叠面积 > 菜单面积 30%，整体移到角色另一侧（左右中选空间更大的一侧）。
5. 高度自适应：`h` 取实际 `getBoundingClientRect()`，不再用 `MENU_H` 估值；首帧 `visibility:hidden` 定位后再显示，避免跳一下。

### 3.4 键盘与无障碍

- `↑ / ↓ / Home / End` 移动高亮，`Enter` 执行，`→` 进入 L2，`←` 返回 L1，`Esc` 逐级退出。
- L2 中直接键入字符 → 聚焦搜索框并输入（菜单打开即可打字）。
- `role="menu" / "menuitem"`、`aria-haspopup`、`aria-expanded`；打开时焦点落到首项，关闭后焦点回到角色热区。

### 3.5 图层与点击穿透

沿用现状：菜单打开 → 整窗掩码置 1（保证菜单外缘可点），关闭 → 恢复 sprite alpha 掩码。新增约束：**菜单与气泡矩形不相交**（由 §4.2 的气泡限宽 + §3.3 的避让共同保证），所以不需要调整 z-index 顺序。

## 4. 视觉规格

### 4.1 卡片与条目

| 项 | 值 |
|---|---|
| 卡片宽 | 216px（槽位 `MENU_SPACE` = 232：216 + 两侧各 8px） |
| 圆角 / 内边距 | 14px / 6px |
| 背景（暗） | `rgba(26, 33, 48, 0.96)`（不加 `backdrop-filter`：透明窗口里采样不到桌面，只剩开销） |
| 描边 | `1px solid rgba(255,255,255,.07)`（向内高光，替代外发光） |
| 阴影 | `0 14px 34px rgba(0,0,0,.38)` |
| 行高 | 32px（窗口高 < 300 时不缩行高，改为主菜单单层滚动，避免文字被挤扁） |
| 字号 | 条目 12sp / 分组标签 10.5sp 600 / 二级说明 10.5sp |
| 文字 | 主 `#e7edf7`，次 `#93a2b8`，强调 `#6ea8fe` |
| hover | 整行 `rgba(110,168,254,.14)` + 左侧 3px 强调条（**不再满行饱和蓝**） |
| active | 左侧 4px 实心圆点 + 强调色文字（用于当前形象 / 网关运行中） |
| 禁用 | 45% 透明度，`cursor: default` |
| 分隔 | `1px rgba(255,255,255,.06)`，上下 6px |
| 滚动条 | 宽 4px、`rgba(255,255,255,.18)`、透明轨道；滚动区顶部/底部各 12px 渐隐提示还有内容 |
| 动效 | 150ms `cubic-bezier(.2,.8,.2,1)`，`scale(.97→1)`，`transform-origin` 跟随翻转方向 |

### 4.2 气泡与卡片不再打架

`pet.css` 气泡限宽改为随舞台宽收缩：

```css
.pet-bubble      { max-width: min(230px, calc(100% - 16px)); }
.pet-bubble-long { max-width: min(258px, calc(100% - 16px)); }
```

### 4.3 图标

每条目左侧 14px 单色线性图标（`currentColor`，stroke 1.6）：对话气泡、声波、日历勾、碗、球、星星、插头、九宫格、图层、窗口、定位、刷新、眼睛-斜线。**不使用 emoji**（与二次元素材风格冲突）。

## 5. 信息架构与文案

- **剥离分组前缀**：渲染时对 `label` 做一次规范化，去掉 `余额-` `工作状态-` `点击回应-` `碎碎念-` 四类前缀（与 `GROUP_LABELS` 一致），得到 `钱袋满溢 / 忙碌点按 / 元气挥手`。不改 `manifest.json` 的原始值（保留上游可追溯性）。
- **L1 文案**统一动词短语：`跟我聊聊…` `让它自己说一句` `一键签到` `喂点吃的` `陪我玩会儿` `露一手` `启动 API 网关` / `停止 API 网关` `动作点播…` `形象与位置…` `重新加载` `隐藏桌宠`。
- **网关行**右侧状态：运行中 → 绿点 + `运行中`；停止 → 灰点 + `已停止`。沿用 `pet-update{gatewayRunning}` 实时刷新。
- **L2 分类 chips** 顺序按使用频度：`最近` → `全部` → 业务组（待机/工作/积分/点击/碎碎念）→ 彩蛋组（生活/才艺/节日/特效）。
- **最近使用**：内存保留最近 6 个动作（不落盘，与「桌宠不写业务数据」红线一致），`最近` chip 仅在非空时出现。
- **搜索**：中文子串匹配（`吃` → 吃早餐/午餐/晚餐/西瓜…），不引入拼音库。

## 6. 关键场景走查

| 场景 | 新路径 | 旧路径 |
|---|---|---|
| 让它吃西瓜 | 右键 → 动作点播 → 输入「西瓜」→ 点击 | 右键 → 动作点播 → 展开「生活(28)」→ 滚动 20 行 → 点击 |
| 角色在屏幕右上角 | 卡片向左下翻转，不遮角色 | 固定右侧槽位，可能顶到窗口上沿（P1） |
| `pet_scale=0.6`（窗口 340×216） | L1 自动紧凑 + 单层滚动；L2 搜索优先 | 卡片 300+ 高，三分之二被裁 |
| AI 档位关闭 | L1 少两行，自然变矮 | 同样少两行，但仍在固定槽位 |
| 网关状态变化 | 菜单开着时行内状态点即时改字 | 已支持（`pet-update`），保留 |

## 8. 验收

1. `pet_scale` = 0.6 / 1.0 / 1.5 三档 + 屏幕 150% 缩放：L1、L2、L2b 完整可见，无裁切。
2. `placeMenu` 单测断言：任何 anchor 下菜单矩形都在视口内；与 `petRect` 重叠 ≤ 30%。
3. 气泡最大宽度下，气泡矩形与菜单矩形无交集。
4. 键盘全流程可达（打开 → 移动 → 进 L2 → 输入 → 执行 → 焦点回到热区）。
5. 106 项下输入「吃」，首屏（不滚动）至少可见 8 条结果。
6. 菜单打开 → 关闭后，点击穿透掩码恢复为 sprite alpha（角色四周空白仍可点桌面）。

## 9. 明确不做

- **径向/环形菜单**：106 项无法环形展开，小窗口下更难命中，与「可搜索」冲突。
- **hover 二级子菜单**：无边框窗口边缘误触率高，翻页更稳。
- **拼音搜索**：需额外词典表，体积与收益不匹配；先上中文子串，按反馈再议。
- **浅色主题菜单**：桌宠窗口当前不读应用主题；暗色卡片在浅/深桌面上对比都成立，先不做双主题，避免状态翻倍。
